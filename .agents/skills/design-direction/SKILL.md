# Direct the composition

For each major visual, decide whether the studio can place an existing asset, draw it in the editor, or needs to generate it. If a new pose or illustration will determine the choice of direction, use the host’s available image generator for that study. For a source-faithful subject, explicitly attach the designated originals in a fresh request and check every input slot, including automatic attachments. Label the result as a draft. Pass the original references, desired action, crop and lighting to layered production for the selected version.

**Source assets as the designer.** Start with the files or links the organizer supplied and the commission’s library. For a missing subject, look for the exact variant in the creator’s collection, an official media kit or an appropriately licensed archive. Open the original, verify its identity and resolution, and read the terms for the intended use. Record the source in the asset register. If reproduction rights are unclear, retain the link for reference and find a usable alternative or draw an original. Identify any stand-in when showing the draft. Keep a designated asset exact unless the client authorizes a change. Ask for a specific file when its identity matters and it cannot be found; the organizer need not research routine assets or choose file formats.

For a collection, investigate the actual subjects, audience, distribution and available source assets. Open the supplied originals and destination samples. Request or research specific missing views, materials or behavior only when they change a decision. Record provenance, crop constraints and the aspect each reference governs. Write shared typography, palette, materials and viewing context in `.graphic-design/art-direction.md`. For each graphic, put its purpose, intended action, local departures, available and missing assets, required fields and proof surfaces in its own brief. Cross-check the family against a representative piece. A score table and an avatar can use the same materials while assigning very different jobs to illustration and type. Use these findings with the planning skill before proceeding to detailed drawing.

1. Identify the viewer, viewing conditions and the one action or idea they must take away. Write the first and second things they should see. Collect the real placement if available, such as a host screenshot, packaging dieline, trim proof or stage display. Record the actual crop, size, color conditions and any data fields. For a family, identify the *currently selected* sibling and what makes it belong.
2. Give each reference a job. Identify the exact asset governing identity, another for pose if needed, a particular material or light treatment, and anything shown only for impact. Record what the user praised and what they rejected in the same image. If “purple” refers to an existing rail or brand mark, sample that reference and check the sample beside it. A later request for warm parchment on the panel changes the panel brief. Theme colors need not recolor skin, skies or every surface.
3. Draw two genuinely different arrangements when composition is open. Use the real aspect ratio and the footprint of the longest plausible copy in the intended face. At destination size, follow the reading order or a complete data path. Compare the alternatives on the consequential tradeoff. Preserve the winner and any useful rejected alternative. For a fixed layout, go straight to the measured drawing.
4. Resolve the selected drawing until another maker can place the components without guessing. Mark anchors, actual visible bounds, overlaps, near/far planes, margins, and how the crop changes per format. For a figure, draw the acting hand, limb chain, eyeline and support. For a carton, draw its folds, label plane and silhouette. For a chart, draw real rows, units, legend and extreme values. Set the real typography now. A gray rectangle where the difficult hand, title or longest row goes defers the decision.
5. Make a value and color study. Identify the key light, shadow receiver, surrounding fill and any local accent. For flat work use relative values, paper/ink and negative space. Read it small and in grayscale. Reserve space for the intended secondary subjects. If removing a decorative figure improves the primary task, try that layout before filling the gap.

At thumbnail size, treat the gaps as shapes. Look at the widest uninterrupted field and the tightest cluster. Which subject does the open field frame? Do the small gaps join the right label, mark and value? A bright, textured corner can outweigh a much larger dark field. If the frame feels lopsided, compare the same content with a different crop, grouping, scale or alignment before adding anything. Preserve a generous margin when it makes the subject easier to see. Choose the spacing on the actual piece at its intended size. [Mark Boulton’s worked whitespace studies](https://alistapart.com/article/whitespace/) · [Getty on balance and emphasis](https://www.getty.edu/education/teachers/building_lessons/formal_analysis2.html)

Hand off the selected drawing with a short **keep / change / verify** note, named source files, layer order and open decisions. Specify which decisions the drawing settles and what remains provisional. Inspect and repair this stage before building finish on top of it.
