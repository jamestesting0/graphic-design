# Plan the set and each graphic

Open the collection board and direction. Write the collection aim, deliverable list, order, shared dependencies and delivery conditions in `.graphic-design/collection-plan.md`. If resolving one piece first will settle shared materials or typography, name that piece and the decision it can settle. Other pieces can begin their independent studies. Distinguish a collection-wide change from a local revision.

Write each graphic's stages in `graphics/<id>/plan.md`, alongside its brief. For every stage specify the artifact, creative question, proof size/surface, exit condition and dependent work. A leaderboard might compare two cameras with populated rows before committing to lighting. A bracket should trace an entrant to the champion and test the longest name before commissioning figures. A small role icon should compare silhouettes beside a username before investing in specular detail.

**Guide the choice.** Show comparable drafts of the actual piece. Hold unrelated layers fixed, include the selected baseline, and include omission when ornament is optional. Name the tradeoff visible at use size and recommend a version. Record the chosen option, or exactly what to borrow from each parent. The user can select, delegate, combine, postpone, or stop. For a draft-only request, stop at that decision. For an authorized delegated choice, record the reason and continue.

For an organizer who gives a short brief, ask for the missing event facts together. Own decisions about type, layout, asset search and export. Put ordinary words beside a visible choice, such as “the street your friends will recognize” and “a ticket to a live event.” Record why they picked it. If the set will be posted one piece at a time, carry that reason into each piece’s plan and judge each by itself.

Keep the working version, approved version for each use, stage, work status and next decision current using the setup skill's command guide. On resume, read those records and open the evidence. Reopen the relevant stage if changing camera, source, type metrics, load-bearing pose, or timing invalidates an earlier proof. Finish with a collection contact sheet and per-piece delivery checks.
