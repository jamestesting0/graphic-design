# Build the picture in parts

In a collection, identify the graphic, use, study, selected parents and shared asset versions before editing. Work in an editable folder and save complete source bundles with the setup skill’s version commands. Track the reason for a combined selection alongside its study. For changes to a shared asset, check its consumers before rolling the new version into other graphics.

**Start from a recoverable version.** Record the selected parent, requested edit, viewer-relative location, and protected neighbors. Save the editable master with linked assets, a full-size proof and a placement preview under one stable ID. For an ongoing study, keep a visual index of the latest five distinct choices plus pinned favorites. Preserve older editable sources. Restore into a new version. A crop or a screenshot alone cannot restore a design.

**Build back to front, testing dependent layers early.**

| Pass | Construct | Inspect before continuing |
|---|---|---|
| Base and far plane | Clean plate or substrate, perspective, background shapes and texture. Preserve distinctive landmarks in approved source art. | Compare fixed landmarks against the source at the same crop. Test the plate with proxy subjects and type before investing in fine edges. |
| Supports and occluders | Midground, ledges, surfaces, contact edges, front lip or foreground masks. Keep foreground separate where it crosses a subject. | With covers hidden, draw where each subject lands. Restore them and check continuous occlusion on both sides. |
| Subject by subject | Use the designated product, person or character variant. Place a suitable original pose directly where the brief permits. Record source file, transform, layer and allowed change. | Normalize to one stable part such as head width or housing span. Compare the remaining part ratios, axes, joints, grip and markings against the original. Discount transparent padding, shadow and exhaust. A second angle can resolve foreshortening. |
| Integration | Set depth and orientation before local contrast, color, sharpness and grain. Separate contact darkening from the cast shadow. Clip reflected light to receiving surfaces. | Compare a same-depth neighbor. Trace what bears the weight, what overlaps what, the light direction and softness. For airborne groups, turn the whole rig, including markings, pilot, suspension and outlets. |
| Graphic components | Construct reusable plates, live type, labels, masks, icons and data states. Group them by what a later editor will need to change. | Fill one actual component with an extreme example before multiplying it. Edit one value or replace one image. Check the blank and populated states, crop and alignment in every required format. |

When generating a source-faithful element, make a fresh request from the designated **originals**. Explicitly list every input and role, including any automatic conversation attachments. A crop of an original should have traceable bounds. Carry actual dimensions, landmark relationships, camera, light and the requested change forward in words. Use generated candidates for editor work and visual comparison. Keep them out of later generation slots in this workflow. A source can govern shape while a separate reference governs only lighting.

For a local correction, edit the responsible mask, transform, light pass or type component first. When replacing an isolated limb repeatedly creates another bad joint, rebuild the pose as a connected figure from original references. Check the load from shoulder through hand to the object and recheck the previously approved face, prop, expression and effects. Avoid adding an unrequested handle, ledge or ornament merely to hide the contact problem.

**When the pose must survive regeneration**, mark the permitted repair on the approved proof. Describe the fixed camera and use tight subject bounds with an explicit origin. Give a few normalized landmarks, which way the part faces in depth, what overlaps it, and what it is acting on. For example, two wrist positions can stay fixed while a casting hand turns from the opponent toward the audience. Describe that palm plane and fingertip curl, then test the gesture with effects hidden. Generate the donor from the designated originals. Composite only the needed regions when the user has selected the existing stance. If the user later selects an exact full donor, treat that selection as a new baseline and refit dependent layers.

After assembly, toggle foreground, labels, shadows and effects separately. Compare the assembled result to the retained parent at the same crop. For registered raster exports expected to be identical outside the edit, compare decoded pixels there, including alpha. For reflowed layouts compare anchors, spacing and neighboring content. Reopen the editable package with its dependencies and reproduce the intended output before handing it off.
